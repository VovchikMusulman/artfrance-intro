# ART France — Intro

Windows-приложение: добавляет корпоративное интро ART France в начало видео. FFmpeg уже внутри — сотрудникам ничего устанавливать не нужно.

## Для сотрудников

1. Скачайте **`ART-France-Intro-1.0.1-portable.exe`** из [Releases](https://github.com/VovchikMusulman/artfrance-intro/releases)
2. Запустите файл двойным кликом (установка не нужна)
3. Выберите видео — готовый файл сохранится рядом: `имя_with_intro.mp4`

## Возможности версии 1.1.0

Инструкции по сборке новой версии из исходников приведены ниже.

Перед обработкой можно выбрать скорость основного ролика: 1×, 1.25×,
1.5×, 1.75× или 2×. Звук ускоряется с сохранением высоты голоса.
Ползунок сжатия меняет качество основного видео от привычного (CRF 18)
до сильного сжатия (CRF 32). Чем правее, тем ниже качество и обычно меньше
файл при одинаковой скорости. Точный размер и уменьшение относительно
исходника не гарантируются. Интро сохраняет обычную скорость и качество.
По умолчанию: 1× и CRF 18. Настройки сохраняются для следующих роликов
до закрытия приложения.

После выбора файла автоматически подсчитывается примерный размер результата
с интро: видны индикатор, процент и текущий этап. Для длинного ролика
проверяются три коротких фрагмента, для ролика до 9 секунд — весь ролик.
Интро учитывается отдельно с исходной скоростью и текущим качеством программы.
Оценка показывается диапазоном, а не гарантированным размером; результат
может выйти за диапазон при неоднородных сценах. При смене настроек старый
расчёт отменяется и запускается новый. Можно начать обработку без ожидания
оценки; после завершения отображается фактический размер файла.

## Для разработчиков

```bash
npm install
# корпоративное интро: assets/intro.mp4
npm start
```

Проверка обработки встроенным FFmpeg: `node --test test/video-processing.test.js`.
Проверка состояний интерфейса: `node_modules\.bin\electron.cmd test/renderer-smoke.js`.
Снимки тестового интерфейса сохраняются в `dist/estimate-preview/ui-check`.

Сборка portable `.exe`:

```bash
npm run dist
```

Готовый файл: `dist/ART-France-Intro-*-portable.exe`
